## 0. Порядок действий — верификация ПЕРВЫМ ДЕЛОM

Верификацию канала стоит проходить до всего остального — она разблокирует то, без чего
дальнейшие пункты чек-листа не работают, а сама верификация может занимать время (история аккаунта).

1. **Phone verification (Intermediate features)** — подтверждение номера телефона в Studio.
   Разблокирует: кастомные превью (thumbnails) через Studio **и через API**, видео длиннее 15 минут,
   live-стримы.
   ⚠️ **Подтверждено официально (support.google.com/youtube/answer/171664, 2026-07-04):** один
   номер телефона верифицирует **максимум 2 канала за 365 дней** — лимит сбрасывается только по
   истечении года, поддержка Google **не снимает его вручную**. Частая причина ошибки «Не удалось
   отправить код подтверждения». Также возможны: rate-limit от частых попыток подряд (снимается
   за 24–48ч), виртуальный/VoIP-номер (детектится и блокируется), несовпадение страны номера
   и страны в настройках канала. Голосовой звонок вместо SMS лимит 2/год **не обходит**.
   **Операционный вывод:** при запуске нескольких каналов (biz_failures/psychology/wealth_viz +
   каналы у Нади/Сергея) заранее распределить, чей реальный номер телефона верифицирует какой
   канал — на одном номере больше 2 каналов в год не поднять.
2. **Advanced features** — доп. верификация (ID или ≥2 месяца истории аккаунта без страйков).
   Разблокирует: **кликабельные внешние ссылки** в описании/карточках/конечных заставках, снятие
   жёсткого лимита аплоадов/сутки, подача заявки в YPP, апелляции Content ID.
   ⚠️ **Без этого шага CPA/affiliate-ссылки в описании — просто нередактируемый текст, не ссылка.**
   Для любого канала с моделью «трафик → внешняя ссылка» это блокер бизнес-модели, не мелочь —
   проходить заранее, не откладывать до момента «когда появится сайт».

## 1. Customization (оформление канала)
| Настройка | Значение | Почему |
|---|---|---|
| Аватар | 800×800 px, ≤4MB | Рендерится в ~98×98px на большинстве устройств |
| Баннер — холст | 2560×1440 px | Базовый upload-канвас |
| Баннер — safe-area | **1546×423 px**, строго по центру | Весь текст/лого — только сюда, иначе обрежется на мобильных (70%+ трафика Shorts — с телефона) |
| Описание канала | ≤1000 символов | Первые ~150 символов видны до «Ещё» — туда главные ключевики |
| Ссылки в шапку | до 5 видимых (из ≤14 в разделе ссылок) | Кликабельность самих ссылок зависит от Advanced features (см. §0) |

## 2. Settings → Channel
- **Channel keywords**: ≤500 символов, 7–10 фраз — помогает алгоритму найти seed-аудиторию в первые недели.
- **Страна канала**: должна совпадать с гео монетизации/AdSense.
- **Аудитория (COPPA) на уровне канала**: явно выставить «не для детей», если контент не детский —
  иначе YouTube может отключить комментарии/таргет-рекламу/переходы по ссылкам.
- **«Категория канала»** (не путать с категорией видео) — **такой настройки в 2026 больше нет**.
  Алгоритм профилирует канал через keywords + историю аудитории + per-video категории.

## 3. Upload defaults — не работают на автозагрузку
`Settings → Upload defaults` (License/Category/Language/Comments/Tags) применяется **только к
ручной загрузке через интерфейс Studio**. При загрузке через YouTube Data API эти дефолты
игнорируются — если явно не передать поля в запросе, API подставит свои значения по умолчанию
(например, `categoryId=22` People & Blogs — мусорная категория для discovery).

## 4. Per-video поля — обязательно передавать явно в API-запросе
| Поле | Обязательность | Значение | Примечание |
|---|---|---|---|
| `snippet.categoryId` | де-факто обязательно | `"27"` (Education) для wellness/educational; `"26"` (Howto & Style) — альтернатива | Не полагаться на дефолт API — прилетит 22 |
| `snippet.defaultLanguage` / `defaultAudioLanguage` | рекомендовано | `"pl"` (для PL-канала) | Влияет на SEO и корректность автосубтитров/автоперевода |
| `status.selfDeclaredMadeForKids` | **да, юридически (COPPA)** | `false` (если не детский контент) | Неверная простановка/пропуск поля — риск страйка |
| `status.privacyStatus` | да | `public`/`private`/`unlisted` | — |
| `status.publishAt` | нет | ISO 8601 | Работает только если `privacyStatus=private` |
| `status.license` | нет | `"youtube"` | Не Creative Commons — не отдаём права на реюз |

## 5. Обложки (thumbnails) через API
- Требует **пройденной Phone verification** (см. §0) — без неё `thumbnails.set` падает
  и это ограничение нельзя обойти через API, только пройти верификацию.
- Файл: **≤2MB**, JPG/PNG/GIF (WebP часто даёт ошибку), минимальная ширина 640px, рекомендуется 1280×720.
- OAuth scope: `youtube.upload` (или `youtube.force-ssl`).
- Между `videos.insert` и `thumbnails.set` — пауза/retry с backoff: слишком быстрый вызов подряд
  ловит race condition (видео ещё не проинициализировано на всех шардах).

## 6. Субтитры — вшитые (burned-in) недостаточно для SEO
Дублировать вшитые субтитры отдельной дорожкой через `captions.insert` (`.srt`/`.vtt`):
вшитый в кадр текст не читается поиском и не участвует в автопереводе плеера, отдельная
дорожка — читается и индексируется.

## 7. Монетизация (YPP) — актуальные пороги
| Tier | Условие |
|---|---|
| Tier 1 (Fan funding, Super Thanks/Shopping) | 500 подписчиков + 3M просмотров Shorts за 90 дней, ИЛИ 3000 watch hours/год |
| Tier 2 (реклама в Shorts Feed) | 1000 подписчиков + 10M просмотров Shorts за 90 дней, ИЛИ 4000 watch hours/год |

## 8. Частые ошибки API — как отличать
| Ошибка | Причина | Что делать |
|---|---|---|
| `403 quotaExceeded` | Исчерпана квота проекта (10000 ед/день) | Сброс в 00:00 Pacific, либо резервный GCP-проект |
| `403 uploadLimitExceeded` | Внутренний лимит канала (не квота API) | Ждать ~24ч, зависит от траста канала |
| `400 invalidMetadata` | Битые поля snippet/status | Чаще всего — `publishAt` в прошлом или невалидный `categoryId` |
| `403 forbidden` (thumbnail) | Канал не верифицирован по телефону | Пройти Phone verification (см. §0) |
| `404`/`503` (thumbnail сразу после insert) | Race condition | retry с backoff |

## Находки по каналу @VitalLogic-nutriFlow (проверить прямо сейчас)
1. **Вероятный root cause прошлого бага с обложками** — не верифицирован номер телефона канала.
   Проверить: Studio → Settings → Channel → Feature eligibility (или Advanced settings — там
   показывается статус Intermediate/Advanced features).
2. **Проверить Advanced features уже сейчас**, не откладывая до сайта — если не пройдены, будущие
   affiliate-ссылки в описании не будут кликабельны в принципе. Верификация может требовать
   истории аккаунта — чем раньше начать, тем раньше будет готово к моменту, когда появится сайт.
3. Свериться: заполнены ли Channel keywords, совпадает ли страна канала с целевым гео (PL).
4. При включении реальной автозагрузки через API — сверить `image_agent`/будущий `youtube_publish.py`
   на предмет `categoryId=27`, `selfDeclaredMadeForKids=false`, задержку перед `thumbnails.set`.
