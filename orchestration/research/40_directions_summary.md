## 2. Ключевые сквозные находки

- **Квиз-воронка — наш главный актив.** Один и тот же паттерн (видео → квиз → персональная
  корзина → affiliate) масштабируется на 4 из 5 направлений (БАДы, собаки, longevity,
  фитнес; для валидатора — квиз как лид-магнит перед платным отчётом). Стоит строить
  **переиспользуемый квиз-движок**, а не одноразовые сайты.
- **Riтoрика «научного репортёра»** («According to a 2025 study…») — универсальный обход
  YMYL для всех health-ниш; директивные советы запрещены (R34).
- **Маркировка AI-контента обязательна** (SynthID/C2PA-сканеры платформ): чекбокс
  «Altered/Synthetic» при каждой загрузке, иначе демонетизация/бан (R34, R36).
- **MMO-лексика — теневой бан**: guaranteed success, passive income, make money online и
  т.п. вычищать из скриптов канала валидатора; прогонять через banned-words checker (R36).
- **Бенчмарки решений** (R38): главная метрика — Viewed-vs-Swiped (<40% kill, >65% scale);
  вердикт по нише — только после ~30 роликов; YT Shorts 30-40с, TikTok >61с (CRP);
  кросспостинг — с анти-дедупликацией через ffmpeg.
- **Проект-аналог** (`creative production scheme`, R39) — рабочая production-система
  польского wellness-канала: забрать `cost_tracker.py`, HTML/GSAP-обвязку рендера,
  `publishers/youtube.py`, ThumbnailPlan/CreativeQA-контракты, OOM-ретрай-протокол.
