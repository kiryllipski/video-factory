## 0в. Новое (2026-07-15) — критичный баг автозагрузки починен + AI-раскрытие не работает (нужен re-auth)

**Баг найден и починен:** SCOPES для `publishers/youtube.py` ранее правились задним числом (добавлен
`force-ssl`), это сломало `creds.refresh()` для уже выданного токена (`invalid_scope`) — из-за этого

отработала «тихо» (без видимой ошибки в статусе задачи). Фикс — `_load_creds` больше не форсирует
SCOPES при чтении токена, читает scopes из самого файла (`autopilot_factory/publishers/youtube.py`).
Проверено (`whoami` работает). **Урок на будущее:** менять SCOPES только вместе с немедленным `auth`.

не применяется даже на `videos.insert` с scope `youtube.upload` (не только на `update`, как считалось
раньше) — нужен `youtube.force-ssl`, для получения которого нужен **интерактивный браузерный `auth`**
(не выполнимо в non-interactive сессии). Из-за этого **ВСЕ 14 роликов, залитых на 2026-07-15
(8 предыдущих + 6 из этой партии), ушли БЕЗ AI-пометки**, включая уже `public`. Код теперь честно
предупреждает при заливке (не молчит), но сам re-auth сделать не может — **нужно действие владельца**:
`python3 autopilot_factory/publishers/youtube.py auth --channel vitallogic_bad_pl --client-secret <path>`
