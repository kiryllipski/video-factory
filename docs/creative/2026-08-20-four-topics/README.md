# VitalLogic — четыре темы: сценарии и сториборды

Подготовительный пакет от 2026-08-20. Это **не production package** и не команда на сборку или публикацию. Здесь только редакционная разработка: русские сценарии, Hook Lab, 12-кадровые визуальные планы и листы-сториборды.

## Общая режиссура

- Формат: 25–32 секунды, 10–12 смысловых битов.
- Вход: конфликт виден без звука в первом кадре; первое слово совпадает с визуальным конфликтом.
- Ритм: минимум три визуальных события в первые шесть секунд; соседние кадры меняют крупность, доказательство или вопрос зрителя.
- Масштабы: `extreme_macro`, `macro`, `medium`, `wide`, `abstract`; один масштаб не повторять более двух кадров подряд.
- Стиль: яркий 2D hand-drawn cartoon, толстый чёрный контур, flat cel shading, cyan / lemon / mint / pink / lilac / warm cream, оригинальный офисный аналитик-скептик, лёгкая ирония без тревожной медицинской подачи.
- Герой для всех четырёх концептов: взрослый оригинальный офисный аналитик, короткие тёмно-каштановые волосы, круглые очки, мятная рубашка, лимонно-жёлтый жилет, тёмно-синие брюки, красный блокнот; лицо и одежда неизменны, эмоция и жест меняются от кадра к кадру.
- Надписи в листах-сторибордах не являются финальным viewer text. Точный текст и цифры позже добавляются детерминированным рендером.

## Приоритет Hook Lab

1. **Cytryna do gorącej herbaty** — миф с польской бытовой узнаваемостью; первый визуальный конфликт должен быть максимально ясным.
2. **Sok jabłkowy czy cola** — двойной объект и быстрый reveal на этикетке.
3. **Czy mikrofalówka niszczy witaminy** — разрушение знакомого страха через бегущие «витамины» и зелёную воду.
4. **Kiszone czy kwaszone** — детектив по составу и процессу, не спор о двух словах на лицевой стороне.

## Источниковая рамка

- Лимон/алюминий: EFSA по совокупному пищевому поступлению алюминия и TWI; небольшое исследование на 12 добровольцах по чаю с лимоном; исследование химических форм алюминия в чайном настое.
- Сок/кола: официальный nutrition label Coca-Cola Poland; WHO по свободным сахарам во фруктовых соках; IJHARS по чтению состава сока и нектара; польская санитарная служба по низкому содержанию клетчатки в 100% яблочном соке по сравнению с целым яблоком.
- Микроволновка: первичное исследование PubMed по удержанию витаминов при варке, микроволновке и готовке на пару.
- Kiszone/kwaszone: официальный материал Wojewódzki Inspektorat JHARS на gov.pl о ферментации, добавленных кислотах и бытовом взаимозаменяемом употреблении названий.
