# Комплаенс и QA — делает Claude

Оба гейта Claude выполняет сам. Комплаенс (стадия 4) может ПРАВИТЬ сценарий; QA (стадия 7) —
только фиксирует выводы и не блокирует продакшен. Источники: `research/02_wellness_safe_claims_pl_eu.md`
(YMYL/БАД), `research/24_qa_judge_patterns.md`, `research/01` (ретеншен), studio_context канала.

## Комплаенс → `compliance.json` (схема `ComplianceVerdict`)

Формат:
```json
{
  "passed": true,
  "fixes": ["что заменили и почему — по одной строке на правку"],
  "cleaned_script": { "...полный объект Script..." }
}
```
- Если всё чисто: `passed=true`, `fixes=[]`, `cleaned_script` = исходный сценарий без изменений.
- Если правил: `passed=false` (или true с правками), внеси **минимальные** правки прямо в `cleaned_script`,
  перечисли их в `fixes`. Дальше пайплайн использует `cleaned_script`.

Что проверяешь (в порядке важности):
1. **Стоп-листы канала** из studio_context. Никаких мед./фин. обещаний, если канал YMYL.
2. **YMYL (finance/health, напр. wealth_viz):** только образовательные формулировки, без гарантий доходности
   и мед. эффекта. Для БАД/wellness (PL/EU) — БАД это еда, не лекарство: запрещены
   `leczy/zapobiega/choroba/ból/terapia`, пользу — только авторизованными EFSA-claim'ами, без «белых халатов».
   Это твёрдое требование (ст. 27 ustawy o bezpieczeństwie żywności i żywienia + EU Reg. 1924/2006).
   **Плашка/спетый диктором текст «Suplement diety» в кадре — НЕ юридическое требование** (проверено
   владельцем 2026-08-04: закон требует не утверждать лечебный эффект, не требует конкретной надписи
   в видео-рекламе — она только для этикетки упаковки, отдельным rozporządzeniem). Раскрытие остаётся
   в description (см. studio_context §7) — этого достаточно.
   Полный свод — `orchestration/research/02_wellness_safe_claims_pl_eu.md` (⚠️ там плашка ошибочно
   названа обязательной — см. правку 2026-08-04 вверху файла).
3. **Факт-чек:** имена/суммы/даты/события правдоподобны и не выдуманы. Для древних/спорных историй —
   «by some estimates / according to some accounts / circa», без выдуманной точности (см. biz_failures §7).
4. **Товарные знаки/лица:** нет призыва воспроизводить действующие бренды/реальных живых лиц вне public-domain;
   исторические — ок.
5. **Хук ↔ тело:** хук не обещает того, чего нет в теле (анти-clickbait).
6. **Тон** соответствует studio_context.

## QA → `qa.json` (схема `QAReport`) — advisory, НЕ блокирует

Формат:
```json
{
  "passed": true,
  "checks": [ { "name": "hook_strength", "passed": true, "detail": "" } ],
  "notes": ["1–5 коротких конкретных замечаний на будущее"],
  "blame_stage": ""
}
```
Оцени сценарий (`cleaned_script`) + `frame_plan` по чек-листу — по одному `QACheck{name,passed,detail}` на пункт:
- `hook_strength` — хук цепляет в первые 1–3 сек, без приветствий.
- `hook_speed` — **v2:** симптом/боль назван голосом в первых 3 словах / ≤1.5с; первый бит ≤2.5с;
  в хуке нет жаргона, которого зритель не знает.
- `hook_dedup` — **v2:** бит 2 не пересказывает хук — сразу механизм/конфликт/цифра.
- `hook_match` — обещание хука раскрыто в теле (нет clickbait-drop).
- `poster_first_frame` — **v2:** `poster_text` заполнен (язык канала); кадр 1 —
  человеческий контекст с чистой верхней третью, НЕ «предмет на фоне».
  **v3:** постер ≤4 слов, есть акцент-слово (*słowo*); ПРОБЛЕМА в кадре-0 видима крупно
  (читается с миниатюры за 0.3с), не «намёк на проблему».
- `cta_plate` — **v3:** заполнен (≤5 слов, бинарный вопрос), перекликается с
  cta/pinned_comment; вместе с loop_closure даёт петлю «конец = начало».
- `frame_argument` — **v3:** каждый кадр — визуальный ДОВОД своего бита, не «обои»
  (тест: закрой voiceover — что утверждает кадр?). Generic-сцены (блокнот/стакан/нейтральный
  интерьер без связи с битом) — fail с указанием номера кадра.
- `pacing` — биты 1.5–2.5с; нет запланированной статики >3с (проверь `motion`/`dur_s` кадров).
- `caption_len` — `on_screen_text` 2–4 слова, safe-зона (нижняя треть).
- `visual_consistency` — единый grade/light/lens во всём FramePlan; кадров = битов, порядок совпадает.
- `open_loop` — есть петля/мостик, удерживающий внимание (~10–12с).
- `loop_closure` — **v2:** финал подводит к началу (ролик закольцован) или CTA отсылает к симптому хука.
- `cta` — есть внятный CTA; **v2:** для каналов с pinned_comment — CTA-вопрос бинарный/острый.
- `compliance_flags` — нет мед./фин. обещаний вне правил канала; для YMYL — дисклеймер присутствует.

Правила вывода:
- `passed=true`, если критичных провалов нет (это подсказка, а не блокировка).
- `blame_stage` — куда бы вернуть при желании доработать: `scriptwriter` | `visual` | `assembly` | `""`.
- Пиши честно, но не блокируй прогон. Если видишь дешёвую правку — лучше внеси её в артефакт до build_media.
- **v3:** в `notes` добавь строку `hook_lab: <отвергнутые варианты хука/постера кратко>` —
  копится статистика, какие формулы хука выигрывают отбор.

## v3: машинный QA пикселей (автоматика build_media, не Claude)

Два новых машинных гейта живут В build_media.py и не требуют действий при авторинге:
- **frame-QA** — каждый PNG после генерации проверяется vision-моделью (текст в кадре, рамки,
  анатомия, нижняя треть, для кадра-0 — верхняя треть); fail → автоперегенерация кадра (≤2).
  Итог — `frame_qa.json`. Если кадр принят «с непройденным чеком» — отсмотреть глазами.
- **video-QA** — 3 стоп-кадра готового out.mp4 (t=0/40%/конец): постер/субтитры/CTA-плашка
  читаемы. Итог — `video_qa.json`, advisory. Претензии чинить пересборкой или правкой стиля.
