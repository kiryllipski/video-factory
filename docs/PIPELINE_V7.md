## Команды

```bash
cd autopilot_factory
python3 engine_v7.py --topic "<тема>" [--format tier_list] [--slug s] [--sfx data] [--go]
python3 engine_v7.py --rebuild runs/<ch>/<run> [--sfx soft]   # пересобрать, БЕЗ вызовов API
python3 engine_v7.py --remix   runs/<ch>/<run>                # все звуковые профили + катушка
```

Без `--go` выполняются только текстовые стадии (сценарий/комплаенс/кадровый план/пакет
публикации) — можно почитать и выбросить, стоит центы.
**Сборки только последовательно, одна за раз** (правило репозитория: параллельные прогоны
вешают машину).

## Три вещи, которые нельзя сломать

1. **Формат — поле контракта, а не рубрика.** 11 форматов, ротация механическая
   (`pick_format` банит два последних, `mistake` ограничен ~12%). До v7 все 100 роликов шли
   одной схемой «симптом → ошибка → фикс» — это и была причина падения канала.
2. **Правило, которого нет в коде, не существует.** «Кадр = довод», «план ≤2.5с», «ротация
   крупности» жили в промптах с v2 и не исполнились ни разу за 100 роликов. Работать они
   стали, только когда превратились в `validate_script` / `validate_plan`.
   **Добавляешь требование к качеству — добавляй гейтом, а не абзацем в промпт.**
3. **Информация живёт на экране.** `Overlay` обязателен минимум на 35% битов. Кадр покрывает
   ДИАПАЗОН битов (`beat_from..beat_to`), поэтому кадров 6–10, а не по одному на фразу.

## Стадии и модели

```
формат → сценарий (pro) → комплаенс (pro) → кадровый план (pro) → пакет публикации (pro)
      → QA-судья (pro) → [--go] кадры (Nano Banana 2 + vision-QA) → TTS → сборка
```

Машинные гейты стоят между стадиями: провал → **одна** попытка переписать с перечнем
нарушений, потом отказ прогона. QA-судья (LLM) проверяет только смысл — членство в списках
и числа проверяет код, потому что судья на этом врёт (проверено).

## Стоимость

$0.38–0.49 на ролик при потолке $1. ~60% — картинки, остальное текст. Кадров меньше, чем в
v3, потому что графика бесплатна: снижение стоимости здесь — следствие, а не цель.

## Звук

Профили в `assembly_v7.SFX_PROFILES`: `none` · `minimal` · `soft` · `data` (дефолт) · `dense`.
Значение в таблице профиля — **целевой пик в готовом миксе (dBFS)**, а не «приглушить на N дБ»:
сэмплы бандла лежат на разных уровнях, и каждый измеряется и приводится к цели.
У профиля обязан быть фолбэк `overlay:*`, иначе часть графики появляется молча.

Микс: голос → −17 LUFS (запас под SFX) → сумма → замер → постоянное усиление до −14 LUFS →
лимитер. Нормализация двухпроходная намеренно: однопроходный `loudnorm` ведёт усиление
динамически и локально гасит отдельные SFX.

`--remix` переозвучивает ГОТОВОЕ видео всеми профилями за секунды — подбирать звук ушами дёшево.

## Грабли, на которые уже наступили

| Симптом | Причина | Где смотреть |
|---|---|---|
| Ободранные этикетки на банках | правило «фактура и следы использования» в studio_context — промпт дословно просил `worn label` | правило снято, износ в негатив-блоке |
| Предмет выселен за край, полкадра пустой поверхности | правило «оставляй середину свободной под графику» понято буквально | переформулировано: «не по центру», а не «освободи середину» |
| «Звуков нет» | три причины сразу: нет фолбэка `overlay:*`; уровни задавались как приглушение сырого сэмпла; голос стоял впритык к лимитеру и тот съедал SFX | `SFX_PROFILES`, `_peak_dbfs`, двухпроходный микс |
| Графика пропадает не вовремя | окно было «до конца следующего бита» — при плотной графике гасло раньше своей фразы, при редкой висело на чужих | `_overlay_clips`: свой бит + хвост 0.35с |
| Регулярная пульсация картинки | толчок масштаба на каждой границе бита внутри кадра | убран, ритм держат графика и субтитры |
| Рывок кадра на стыке чанков рендера | относительный твин (`+=`) писал то же свойство, что основное движение | толчок на обёртке, абсолютные значения |
| Пустой/белый кадр при перемотке | `tl.from` оставляет элемент видимым до инициализации твина | везде `tl.set(...,0)` + `fromTo` |
| Субтитры и графика смещены на 35px влево от центра кадра | асимметричные отступы (`left:70/right:140`) — блок центрирован внутри своей коробки, а коробка сдвинута; постер и payoff-карточка с симметричными отступами стояли ровно, отчего разнобой был заметнее самого сдвига | `SAFE_SIDE` — симметричный боковой отступ для всего центрированного контента |
| Текст финальной карточки уезжал за края | `<span>` акцента внутри flex-контейнера становится отдельным flex-элементом | обёртка `.poinner` |

**Проверяй линтер hyperframes в выводе рендера.** Строки с `✗` — реальные ошибки
детерминизма и видимости, а не придирки; три бага из таблицы выше нашёл именно он.
