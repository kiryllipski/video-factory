# Обучающий контур

> Замыкает петлю: **гипотеза → метрика → вывод → следующий сценарий.** Без него фабрика
> производит ролики, но не учится — а значит метрики не растут, сколько бы роликов ни вышло.

## Принцип

**Скрипт собирает и соединяет факты. Выводы делает Claude.**

Не зашивать аналитика в код. Статистические пороги в коде устаревают молча и незаметно; Claude
же видит контекст — что менялось в пайплайне, что происходило на канале, какой ролик выпал из
ряда и почему — и рассуждает на нём. `learning_loop.py table` готовит таблицу, дальше работает
голова, а не `if views > threshold`.

## Данные

| Файл | Что внутри | Кто пишет |
|---|---|---|
| `experiments.jsonl` | Один ролик = одна строка: рычаги, которыми он отличается от других | `learning_loop.py register` / `backfill` |
| `metrics.jsonl` | Снапшоты метрик из YouTube Analytics API, append-only | `learning_loop.py collect` |
| `studio_metrics.jsonl` | Ручные выгрузки Studio: Impressions, Stayed to watch | импорт CSV |
| `HYPOTHESES.md` | Активные гипотезы со статусами и выводами | Claude |
| `learnings.json` | Дистиллят выводов, который читает scriptwriter | Claude |

Всё append-only: снапшот не затирает предыдущий, история метрик сохраняется — это позволяет
видеть динамику, а не только последнее состояние.

## Рычаги (levers)

Извлекаются **механически** из артефактов прогона — руками вводить ничего не нужно:

- из `script.json` — hook и его длина, число битов, хронометраж, средняя длина бита, постер, CTA-плашка
- из `frame_plan.json` — grade / light / lens, число кадров, набор motion
- из `publish_package.json` — заголовок и его длина, `title_template`, число хэштегов, есть ли закреплённый комментарий
- из `run_meta.json` / `cost.json` / `qa.json` — версия пайплайна, стоимость, прошёл ли QA

## Команды

```bash
cd autopilot_factory

python3 learning_loop.py backfill --channel vitallogic_bad_pl   # восстановить историю
python3 learning_loop.py register --channel vitallogic_bad_pl --run <прогон>
python3 learning_loop.py collect  --channel vitallogic_bad_pl   # снять метрики
python3 learning_loop.py table    --channel vitallogic_bad_pl --out /tmp/exp.md
```

Скоуп `yt-analytics.readonly` уже выдан токену `vitallogic_bad_pl` — повторная авторизация не нужна.

## Важное при чтении метрик

- **Сырые просмотры несравнимы** у роликов разного возраста — сравнивать по `views_per_day`,
  всегда указывая `hours_live`.
- **Запланированные (`private` + `publishAt`) ролики метрик не имеют** — они ещё не вышли.
  Не считать их провалами.
- **Impressions и «Stayed to watch» через API недоступны** — только ручная выгрузка Studio.
  По контент-стратегии канала потолок роста — именно показы, поэтому выгрузка раз в 1–2 недели
  не формальность.
- **Batch-публикация душит охват** (подтверждено на данных, `research/53`) — при разборе
  провалов первым делом смотреть, не вышли ли они пачкой.
