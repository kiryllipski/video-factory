# Archived legacy runtime (v1–v6)

Перемещено 2026-08-24 после выбора v8 Codex каноническим production-контуром.
Файлы сохранены без удаления для воспроизводимости старых артефактов и исторических
сравнений. Новые VitalLogic-пакеты не должны импортировать этот runtime.

В активном корне остаются только v8 runtime, его тесты, Codex skill, локальные publishers
и общие инструменты. Старые медиапланы и runtime-промпты также находятся здесь.
