Скопируй эту папку в `config/channel/` и заполни под выбранную нишу (Задача 0):
- `studio_context.template.md` → `studio_context.md` (тон, визуальный код, стоп-листы, CTA)
- `media_plan.template.md` → `media_plan.md` (очередь тем на 30 дней)

Различия ниш живут здесь; ядро движка (`scaffold/engine_local.py`) — общее и нишу не знает.
Стартовые темы под longevity/фитнес — в `media_plan.template.md` (из ресёрча R34).
