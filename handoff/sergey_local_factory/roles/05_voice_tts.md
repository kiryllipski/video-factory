# Роль: Озвучка (стадия 5)

Инструкция для кода-оператора TTS. Вход: `Script` (реплики битов). Выход: `audio/voice.wav` (+ per-beat при нужде синка).

Инструмент: **Chatterbox Multilingual V3** (MIT, коммерчески чисто), `device="mps"`.
- Загрузка: `ChatterboxTTS.from_pretrained(device="mps")`.
- **Клонирование голоса**: если есть 10-сек референс канала — использовать как voice-preset (консистентный голос бренда).
  Иначе — встроенный голос; зафиксировать выбор в конфиге канала.
- `exaggeration` — выразительность под динамичные Reels (не переусердствовать, речь должна быть разборчивой).
- **Темп**: если речь медленная — не ставить `tired/slow` в стиль, а ускорять пост-обработкой `ffmpeg atempo=1.10-1.15`.
- Генерировать **по биту** (отдельный WAV на бит) для точного A/V-синка на сборке; склейка без щелчков (короткий fade или `silenceremove`).
- Мастер-громкость выравнивать на сборке (`loudnorm I=-14` на финальном миксе).
- ⛔ Не использовать XTTS-v2/F5-TTS/Fish Speech для монетизируемых роликов (non-commercial лицензии).
- Языки: EN (Tier-1) по умолчанию; RU/PL — Chatterbox поддерживает, проверить качество ушами.
- Писать в `runs/<...>/audio/` атомарно.
