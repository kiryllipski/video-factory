# Роль: Субтитры (стадия 6)

Инструкция для кода-оператора STT. Вход: `audio/voice.wav`. Выход: `captions.json` (word-level таймкоды).

Инструмент: **whisper.cpp** (Metal), модель `large-v3-turbo`.
- Команда: `./main -m models/ggml-large-v3-turbo.bin --max-len 1 --output-json audio/voice.wav`
  (`--max-len 1` = сегмент на слово → пословные таймкоды для караоке).
- Разобрать JSON в список `{word, start_s, end_s}` → это вход сборщику для караоке-субтитров.
- Проверять швы, если озвучка была per-beat (склейка WAV не должна сдвигать таймкоды).
- Обработка 60-сек аудио — 2-3с; это самый быстрый узел, можно не кэшировать.
- Язык распознавания — из `Script.lang`.
- Писать `runs/<...>/captions.json` атомарно.
