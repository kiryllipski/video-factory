# Роль: Сборка видео (стадия 7)

Инструкция для кода-сборщика. Вход: `BuildManifest` (FramePlan + audio + captions + fps). Выход: `out.mp4` 1080×1920.

Два пути (выбор — из аудита/ответов Задачи 0):
- **hyperframes (рекомендуется для «премиума»)**: собрать HTML/CSS-композицию — кадры как слои-картинки +
  CSS/GSAP-движение (Ken Burns/зум/параллакс) + караоке-субтитры в нижней трети (safe-зона) + плашка-дисклеймер
  ниши. `hyperframes render` → немой mp4, затем мукс озвучки ffmpeg.
- **Голый ffmpeg (минимальная установка)**: движение через `zoompan` (Ken Burns), субтитры — `drawtext`/ASS
  из `captions.json`, конкатенация кадров по таймингам, мукс аудио.

Правила (docs/STRATEGY.md — динамика статики):
- **Никакой статики >3с**: зум/сдвиг на каждом кадре; jump-cut/смена плана каждые 2-3с. Финальный CTA-кадр —
  добавить движущийся слой (progress-bar/pulse), чтобы пиксели двигались.
- **Караоке-субтитры**: 2-4 слова на экране, активное слово подсвечивается (scale ~1.15, ~250мс, pre-roll 50-100мс до звука), строго нижняя треть.
- **Safe-зоны**: ничего важного в верхних ~15% и правой колонке (UI платформ).
- **Звук**: `loudnorm I=-14:TP=-1:LRA=11` на мастер; если есть BGM — ducking под голос
  (`sidechaincompress`), BGM под голосом −26..−30 LUFS.
- **Выход**: 1080×1920, h264, yuv420p, `fps` из манифеста (30). Для кросспостинга — 3 версии с микро-уникализацией
  (шум `noise=alls=1:allf=t`, сдвиг аудио ~50мс, разные метаданные).
- Писать `runs/<...>/out.mp4` атомарно; сохранять команду ffmpeg в лог прогона.
