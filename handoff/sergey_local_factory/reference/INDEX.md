# reference/ — справочные наработки (ресёрч фабрики)

> Готовые своды из основной фабрики, релевантные локальному производству. Это **контекст**,
> а не инструкции к исполнению (инструкции — в `AGENTS.md`, `docs/`, `roles/`). Codex читает их,
> когда нужно принять решение по стадии; Сергею полезны `PLAYBOOK` и `34_...` (его ниша).
> Колонка «кому»: 🤖 Codex (техника), 👤 Сергей (стратегия/ниша), 👥 обоим.

## Плейбук
| Файл | Кому | О чём |
