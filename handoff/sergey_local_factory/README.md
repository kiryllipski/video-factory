# Локальная фабрика faceless-видео — старт для Сергея

Привет! Это заготовка проекта, который на твоём Mac (M4 Pro, 48 ГБ) будет **сам делать
короткие вертикальные видео 9:16** (Shorts/Reels/TikTok) — из темы: сценарий → картинки →
озвучка → субтитры → готовый ролик. Всё работает **локально, без платных ключей**.

## Что делать (2 шага)

1. Распакуй архив и **открой папку `sergey_local_factory/` в Codex как проект**.
2. Codex прочитает `AGENTS.md` и **первым делом** (это встроено как обязательная Задача 0):
   - проверит, что уже установлено на твоей машине (в т.ч. ComfyUI, если он у тебя есть);
   - задаст тебе несколько вопросов (какая ниша канала, язык, какую модель картинок пробовать, есть ли образец голоса);
   - покажет план разворачивания и **спросит твоё «ок»** перед установкой;
   - коротко объяснит, что будет происходить.

Просто ответь Codex на вопросы и подтверди план. Дальше он поставит стек, соберёт пайплайн
и сделает один тестовый ролик, чтобы ты посмотрел.

## Что понадобится от тебя по ходу
- Ответить на вопросы Задачи 0.
- Записать ~10 секунд своего (или нужного) голоса — если хочешь фирменный голос канала (иначе будет встроенный).
- Посмотреть первый ролик и сказать, что поправить.

## Важно
- Ничего не покупаем и не подключаем облако — всё считается на твоём Mac.
- Если Codex просит что-то удалить/перезаписать или скачать много гигабайт — он спросит; смотри, что подтверждаешь.

## Структура (для любопытных)
- `AGENTS.md` — инструкции для Codex (начинается с обязательной Задачи 0).
- `docs/` — как всё устроено, как ставить, как писать промпты для картинок, стратегия канала.
- `roles/` — «должностные инструкции» для каждого шага пайплайна.
- `contracts/`, `config/`, `scaffold/` — техническая начинка, её доведёт Codex.
